# v0.1.0: Bounded AgentCore broker safety evaluation

This release demonstrates one narrow claim: a Nova Micro broker running in AgentCore Runtime can gather synthetic evidence through a policy-governed Gateway, while exact approval and retry safety remain enforceable outside the model.

## Included

- Two read tools visible to the Runtime workload identity
- One remediation tool reserved for a separate operator identity
- AgentCore Policy verification in `LOG_ONLY` before promotion to `ENFORCE`
- Target-side action validation and exact approval binding
- DynamoDB conditional commit, replay handling, and receipt reconciliation
- Task-correlated Runtime, Gateway, Lambda, and ledger evidence
- Credential-free offline tests and demonstration through Podman
- Explicit deployment and complete teardown through Make

## Verified result

- 52 account-free tests pass.
- The 12-case offline demonstration passes without networking or credentials.
- Live Gateway verification passes in shadow and enforcement modes.
- Nova Micro uses both read tools and proposes the bounded action without executing it.
- Approved remediation commits one synthetic effect.
- Changed arguments and consumed approval reuse are denied.
- Simulated post-commit response loss reconciles to the existing receipt.
- Application and bootstrap stacks are absent after teardown.

See [AWS release evidence](../../artifacts/aws-release-evidence.md) for the normalized live results.

## Limits

This release is not a production incident platform and does not claim general exactly-once delivery. It uses one synthetic service, one model, one Region, one Runtime, and one authoritative ledger. It does not implement end-user delegation, multiple agents, Memory, A2A, a user interface, or real infrastructure changes.
